# ARTI 403 - Image Processing
 
Lab work for ARTI 403 (Image Processing), covering practical image processing techniques implemented in Python.
 
## Structure
 
```
├── Lab01/
│   ├── lab01.ipynb
│   └── README.md
├── Lab02/
│   ├── lab02.ipynb
│   └── README.md
└── README.md
```
 
Each lab folder contains the notebook for that lab and its own README describing the topic, approach, and any notable results.
 
## Tech Stack
 
- Python
- Jupyter Notebook
- OpenCV / NumPy / Matplotlib
## How to Run
 
```bash
pip install -r requirements.txt
jupyter notebook
```
 
Open the desired lab's notebook and run the cells in order.
